# CareerForge — MVP Prioritization (MoSCoW)

> Source: CareerForge Complete Requirements Package v1.0. Companion documents: see /architecture folder for technical design

## 7. MVP Prioritization (MoSCoW)
**MUST HAVE (MVP)**
FR-001–FR-006, FR-008–FR-012, FR-014, FR-020–FR-023, FR-025, FR-028, FR-030–FR-033. In plain terms: auth, personal info + photo, experience (+achievements), education, skills, projects, resume creation with section/record selection and reordering, one template, PDF export, resume duplication and deletion.

**SHOULD HAVE (fast follow, v0.2–v0.3)**
FR-007 (multiple summaries), FR-015–FR-018 (certifications/awards/leadership/languages), FR-024 (per-resume overrides), FR-026–FR-027 (theme/font), FR-029 (ATS mode), FR-034–FR-036 (job description analysis).

**COULD HAVE (later, v0.4+)**
FR-013 (skill proficiency), FR-019 (references), FR-037–FR-039 (public portfolio).

**FUTURE (not committed)**
FR-040 (AI-assisted suggestions) and anything from the original brief's Phase 13+ not listed above.

This is intentionally a smaller MVP than the full 16-phase brief — it proves the core master-data/resume-presentation architecture with the least surface area, consistent with the SRS's MVP proposal.
