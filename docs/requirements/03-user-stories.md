# CareerForge — User Stories

> Source: CareerForge Complete Requirements Package v1.0. Companion documents: see /architecture folder for technical design

## 3. User Stories
Grouped by feature area. IDs are prefixed `US-` and referenced later in the Traceability Matrix (Section 11).

**Authentication**
- US-001: As a new user, I want to register with email and password, so that I can create my own private career profile.
- US-002: As a returning user, I want to log in, so that I can access my data.
- US-003: As a user, I want to reset my password if I forget it, so that I'm not permanently locked out.
- US-004: As a user, I want to log out, so that my account is protected on shared devices.

**Profile Management**
- US-005: As a user, I want to enter my personal information (name, title, contact, links), so that it can appear on any resume.
- US-006: As a user, I want to upload a profile photo, so that resumes that use photos can include it.
- US-007: As a user, I want to write multiple named professional summaries, so that I can pick the right one per resume.

**Experience**
- US-008: As a user, I want to add a work experience entry with dates, organization, and description, so that it's part of my career profile.
- US-009: As a user, I want to add individual achievement bullet points under an experience, so that I can select which ones appear on a given resume.
- US-010: As a user, I want to mark an experience as "current," so that I don't need an end date.
- US-011: As a user, I want to edit or delete an experience, so that my profile stays accurate.

**Education**
- US-012: As a user, I want to add education entries with institution, qualification, and dates, so that they can appear on resumes.

**Skills**
- US-013: As a user, I want to add skills grouped by category (technical, soft, tools, etc.), so that resumes can show relevant groupings.
- US-014: As a user, I want to optionally indicate proficiency for a skill, so that I can signal skill depth if relevant.

**Projects**
- US-015: As a user, I want to add a project with description, technologies, and links, so that I can showcase relevant work, especially as a student with limited job experience.

**Certifications**
- US-016: As a user, I want to add certifications with issuing organization and dates, so that they appear where relevant.

**Awards**
- US-017: As a user, I want to add awards with organization and date, so that they can strengthen a resume.

**Languages**
- US-018: As a user, I want to list languages and proficiency, so that multilingual ability is represented.

**Resume Creation**
- US-019: As a user, I want to create a new resume from my career profile, so that I have a targeted document for a specific role.
- US-020: As a user, I want to select which career profile sections appear on a given resume, so that irrelevant information isn't included.
- US-021: As a user, I want to select which specific records (which experiences, which achievements, which skills) appear on a resume, so that I control relevance and length.
- US-022: As a user, I want to reorder sections and items within a resume, so that the most important information appears first.

**Resume Customization**
- US-023: As a user, I want to choose a color theme and font for a resume, so that it matches my personal brand or the target industry.
- US-024: As a user, I want to override the wording of a specific achievement just for one resume, so that I can tailor phrasing without changing my master data.

**Templates**
- US-025: As a user, I want to choose from multiple professional templates, so that I can pick a style that fits the role I'm applying for.

**ATS Mode**
- US-026: As a user, I want to generate an ATS-friendly version of a resume, so that I have a safe option for applicant tracking systems.

**PDF Export**
- US-027: As a user, I want to export a resume as a PDF, so that I can submit it to employers.

**Resume Duplication**
- US-028: As a user, I want to duplicate an existing resume, so that I can quickly create a variant without starting over.

**Job Description Analysis**
- US-029: As a user, I want to paste a job description and compare it against my profile, so that I can see which requirements I already meet and which are missing.

**Public Portfolio**
- US-030: As a user, I want to optionally publish a public portfolio page, so that I can share my career profile via a link.
- US-031: As a user, I want to control exactly what appears on my public portfolio, so that I don't expose information I consider private.
